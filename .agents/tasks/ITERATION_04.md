## Kontrak aktif

- Urea granular bulk, Handysize milik, 30.000 MT, Bontang–Mundra/WCI, satu arah laden-only termasuk muat/bongkar. Q/rute input, bukan konstanta fungsi.
- OD satu pengiriman satu arah dengan biaya internal termasuk balik. Utuh/read-only, informatif, bukan gate/margin/penghematan.
- Tanggal sumber berbeda ditoleransi untuk simulasi; unit/produk/FOB basis/finite/critical arithmetic tetap dicek. Clock tender = cutoff kasus.
- FOB = indeks + alpha sekali; CFR = FOB + freight tetap. Alpha tidak mengubah biaya freight bila voyage sama.
- Gate A last active + FOB >= OE/HPS; ranking kandidat, bukan award. Gate B gross-DWT screen + kontribusi baseline >= 0. Impas lolos, stress negatif bukan veto.
- Hanya GO/NO GO. Gate A gagal → Gate B belum dievaluasi. Tidak ada fallback profit FOB, margin minimum, laycan hard gate, produksi/hedge atau MVP.
- Python/Decimal menghitung; renderer memformat; snapshot per run tidak dimutasi. I2/I3/sumber dipertahankan.
