# PILOG CFR DSS Skill Catalog

These are local project skills. Load only the skill that materially matches the current task, then follow its `SKILL.md`. They are designed for the simulation-to-final-validation lifecycle, not for production execution.

| Skill | Use when the task concerns |
|---|---|
| `pilog-iteration-governance` | Planning, executing, reviewing, or closing an iteration |
| `pilog-route-data-contract` | CSV/Excel inputs, variable mapping, units, route data, source/freshness, or learning workbook |
| `pilog-voyage-economics` | Freight cost, freight selling rate, voyage cost, TCE, vessel ownership, chartering, or commission |
| `pilog-calculation-engine` | Python module design, formulas, `Decimal`, tests, versioned calculation trace, or refactoring scripts |
| `pilog-prescriptive-dss` | Gate 1/2, scenarios, recommendation status, reason codes, or human approval boundary |
| `pilog-product-business` | Product scope, stakeholder value, UX/output, prioritisation, KPI, or MVP readiness |

## Source precedence shared by every skill

```text
mentor feedback
-> approved business/data contract
-> authoritative source data
-> domain reference
-> LLM suggestion
```

No skill authorises a commercial decision, external integration, quote, booking, fixture, hedge, or write-back.
